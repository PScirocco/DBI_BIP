# BI-sim インストーラ確認チェックリスト（2026-11-25）

**対象**：新しく作ったインストーラ（`BI-sim_setup_YYMMDD.exe`）で、別PCにインストール → 起動 → アンインストールができること（4項目・約20分＋ビルド）。
画面の中身（BC設定の差し替えなど）は開発PCで確認済みなので見ません。

## 準備（ビルドする別PC）

1. 開発PCの `bisim2\` から、次の2つを別PCの `bisim2\` へコピーする（**別PCにある同じ名前のフォルダは先に消してから**）
   - `bisim\`（11/25 の BC設定の差し替え）
   - `installer\`（インストーラの新しいファイル `setup_main.py`・`setup.spec`、`build_exe.ps1` の変更）
2. `bisim2\` で `.\installer\build_exe.ps1` を実行する → 最後に「インストーラ: …\dist\BI-sim_setup_YYMMDD.exe」と出る
3. インストールして確かめるPCに、その `BI-sim_setup_YYMMDD.exe` だけをコピーする（ビルドしたPCでもよい）

## 確認

| 項目 | 手順と期待される結果 | 結果 |
|---|---|---|
| 1 インストール | `BI-sim_setup_YYMMDD.exe` を実行 →「BI-sim セットアップ」の画面が出る（インストール先 `C:\Users\<ユーザー>\AppData\Local\Programs\BI-sim`）→「インストール」→「インストールが終わりました … 起動しますか？」→「はい」→ BI-sim が起動する。※「Windows によって PC が保護されました」が出たら「詳細情報」→「実行」 | |
| 2 ショートカット | BI-sim を閉じて、スタートメニューの「BI-sim」と、デスクトップの「BI-sim」から、それぞれ起動できる | |
| 3 更新（上書き） | BI-sim で言語を English に切り替えて閉じる → もう一度 `BI-sim_setup_YYMMDD.exe` を実行 →「前のバージョンがあります。上書き（更新）しますか？」→「はい」→ 起動すると English のまま（設定が残っている） | |
| 4 アンインストール | 「設定」→「アプリ」→「インストールされているアプリ」で BI-sim の「アンインストール」→ 黒い画面で「ログ・設定・出力も消しますか？」→ **Enter**（残す）→ スタートメニュー・デスクトップのショートカットと「アプリ」の一覧から BI-sim が消え、インストール先には `_log_BISim`・`bisim_app.json` だけが残る | |

**後片付け**：インストール先のフォルダ（`…\AppData\Local\Programs\BI-sim`）は消してよい。
