# BI-sim 1ファイル EXE（onefile）確認チェックリスト（2026-11-25）

**対象**：BI-sim.exe を1つの EXE にした（`_internal` フォルダなし）変更だけ（4項目・約15分＋ビルド）。

## 準備（ビルドする別PC）

1. 開発PCの `bisim2\installer\` を、別PCの `bisim2\installer\` へコピーする（**先に別PCの `installer\` を消してから**。`bisim\` は前回のままでよい）
2. `bisim2\` で `.\installer\build_exe.ps1` → 最後に「インストーラ: …\dist\BI-sim_setup_YYMMDD.exe」
   （`dist\BI-sim\` の中は `BI-sim.exe` だけになる）

## 確認（前回インストールしたPCで）

| 項目 | 手順と期待される結果 | 結果 |
|---|---|---|
| 1 更新 | `BI-sim_setup_YYMMDD.exe` を実行 →「上書き（更新）しますか？」→「はい」→ インストール先（`…\AppData\Local\Programs\BI-sim`）に **`_internal` が無く**、`BI-sim.exe`・`uninstall.bat`・ログ・設定だけがある | |
| 2 起動の時間 | スタートメニューの「BI-sim」から起動 → ウィンドウが出るまでの秒数（もう一度起動したときの秒数も） | 1回目　秒 ／ 2回目　秒 |
| 3 計算 | ①②…いつもどおりシーケンス（例：`speedtest_phone\speed-10f.seq.json`）を開いて実行 → 最後まで終わる（計算時間は前と同じくらい） | |
| 4 一時フォルダ | BI-sim を閉じて数秒後、エクスプローラーのアドレス欄に `%TEMP%` と入力 → `_MEI` で始まるフォルダが残っていない | |
