## 3. 作業上の注意

- 作業ツリーには CRLF のファイル（`results.py`・`i18n.py` など）と LF のファイル（`engine.py`・テストなど）が混ざっている。
  Edit ツールは改行を保つ。スクリプトで書き換えるときは改行を保つ（今回は scratchpad の小さな Python で `chr(13)+chr(10)` を扱った）
