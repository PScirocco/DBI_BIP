## 5. 作業上の注意（このセッションで分かったこと）

- **Excel COM を使うときは、PowerShell ツールにコマンドを直接書く。** `powershell -ExecutionPolicy Bypass -File …` は自動判定で拒否された
  - 日本語の文字列は UTF-8 の JSON ファイルに書いておき、`Get-Content -Raw -Encoding UTF8 | ConvertFrom-Json` で読む
  - 日本語のファイル名は `Get-ChildItem '…\*_261022.xlsx'` のようにワイルドカードで掴むと、コマンドに日本語を書かずに済む
- **評価結果 xlsx は C 列に図形（画像のグループ5つ、7〜11行目）がある。** openpyxl で保存すると消えるので、Excel COM で編集する
  - 行の高さを変えるときは、図形の `Placement` を一時的に 2（移動のみ）にして、終わったら戻す
  - 文字が収まらない行だけ `AutoFit` の結果に合わせて高くし、低くはしない（図形のため）
- **GUI のスクリーンショット**：`QT_QPA_PLATFORM` を設定せずに `MainWindow` を作り、`apply_light_theme` → `i18n.set_lang('ja' または 'en')` → `win.grab()`
  - 担当者の設定・ログを汚さないよう、`main_window.APP_CONFIG_PATH` と `Logger` のログフォルダを一時フォルダに差し替える
  - シーケンスは一時フォルダにコピーしてから開き、出力フォルダも一時フォルダにする（自動保存で元のシーケンスが絶対パスに書き換わるのを防ぐ）
  - `QFileDialog.getOpenFileName` を差し替えて `open_sequence()` を呼ぶ → `run_steps("all")` → `win.worker` が `None` になるまで `processEvents()`
  - 英語表示はマップの見出しが長いので、ウィンドウ幅を 1600 程度にする
- Marp の変換ツールはこのPCに無い。PDF は担当者が作る（Markdown と画像を渡す）
- 前回までの注意（`261026_引き継ぎ資料.md` §5）もそのまま有効：Bash のヒアドキュメントで `\\` や `\n` が化ける、日本語入りの .ps1 は UTF-8 BOM、LibreOffice は無い、tools の結果の出力先が既存データを上書きしうる、など
