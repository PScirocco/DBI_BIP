# GUI プロトタイプ（UX 検証用・使い捨て）

`source/` の劣化シミュレータに GUI を被せた PySide6 プロトタイプ。
**画面構成とワークフローの妥当性を確認するための試作**で、本番ツールの土台ではない。
劣化モデル本体（`source/`）は無改変。

## セットアップ

`source/.venv` は壊れているので新規に作る。

```powershell
# リポジトリ直下で
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r prototype/requirements.txt
```

## 起動

```powershell
python prototype/app.py
```

起動時に **サンプルを自動読み込み**する（`source/dbi_common` に入力素材があり、
`source/dbi_output` に既存の実行結果がある場合）:

- `eval_exec.bat` 相当の4ステップ（動画Aging → 静止画PQ評価 → 動画Aging継続 → 静止画PQ評価）を②に登録
- `source/dbi_output/{1..4}_out_img / _deg_* / _stat_*` を⑤結果タブへ読み込み
  → **何も実行せずに劣化画像・劣化率マップ・累積ストレスマップを確認できる**（レビュー用）

「デモ」メニューで再読込 / クリアが可能。

## 画面（5タブ）

| タブ | 内容 |
|---|---|
| ① フォルダ設定 | 6種のフォルダをパス欄＋[参照…]で変更。既定値は `source/dbi_common` 等。ステップ設定でファイルを選ぶと、その親フォルダが自動でここに反映される |
| ② 実行ステップ | ステップ一覧。[追加][複製][削除][↑][↓]。行を選ぶと③へ、ダブルクリックでも③へ |
| ③ ステップ設定 | 選択中ステップの設定。**入力画像 / ヒートマップ / 前回Aging結果 のプレビュー**。初期ストレス＝なし / 前ステップから継承 / ファイル指定。モデルパラメータ表（CSV読込/保存）、Sim条件、将来拡張枠（無効） |
| ④ 実行 | [▶全ステップ][▶選択ステップ][■中断]。全体進捗＋フレーム進捗＋処理中フレーム表示＋ログ＋経過時間 |
| ⑤ 結果 | idx を選択 → 劣化後プレビュー / 劣化率マップ / 累積ストレスマップ / 時系列 / A/B比較（無効） |

劣化率マップ・累積ストレスマップは **各チャネル色の輝度表示**（R→赤 / G→緑 / B→青、
黒=劣化大・明=劣化小）と **RGB合成** を切替。劣化率は 0–1 の絶対輝度、
累積ストレスは全チャネル最大で正規化。カラーマップ選択メニューは無し。

画面は **明るいグレー基調**（OSのダークテーマに関わらず固定。`app.apply_light_theme`）。

**言語切替**：メニュー「言語 / Language」で 日本語(JP) / English(EN) を切替（再起動不要、
入力中の状態は保持）。全UI文字列・実行ログ・エラーメッセージ・サンプルステップ名が対象。
文字列カタログは `prototype/i18n.py`（`STR` 辞書）。追加・修正はここだけ。

## Aging 再開

ステップの「初期ストレス」で **前ステップから継承** を選ぶと、出力フォルダの
`{前idx}_stat_{r,g,b}.csv` を読んでその状態から累積を継続する（既存の `ini_en=1` 相当）。
`idx` は②のステップ並び順（1始まり）。
`eval_exec.bat` の「動画Aging → 静止画でPQ評価 → 動画Aging継続 → …」を
ステップを並べて再現できる。

## Unicode パス対応（重要）

OpenCV の `cv2.imread` / `cv2.imwrite` は Windows で非ASCIIパス
（`C:\ユーザー\horibe\DBI_BIP`）の **静止画（PNG）** を読み書きできない。
プロトタイプは `imio.py`（`np.fromfile`＋`imdecode` / `imencode`＋`tofile`）で回避している。
動画（`VideoCapture` / `VideoWriter`）は Unicode パスでも動作する。

→ **`source/main.py` を直接 or `eval_exec.bat` で実行すると、静止画ステップ
（`eval_img.png`）は現状このパスでは失敗する**（動画ステップは動く）。
本番ツールでは同様の Unicode 対応が必要。

## 既知の制限（プロトタイプなので未対応）

- 処理パイプライン（BIP / DBI補正 / ピーク輝度制御）、A/B比較、BC設定の反映：UIのみ・無効
- exe パッケージング：本番ツールで対応
- エンジンの API 分離リファクタ：本番ツールの最優先課題（`sim_runner.py` はその暫定版）
- 動画の途中中断は「現在フレーム終了後」に停止
- 大きな解像度では CSV 保存・マップ表示が重い
