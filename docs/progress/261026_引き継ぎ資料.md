## 5. 作業上の注意（このセッションで分かったこと）

- **Bash ツールのヒアドキュメント内では `\\` が `\` に、`\n` 等が実際の改行・`\r` に化ける**。Python の置換パッチは Write でファイルに書いてから実行する
- **PowerShell 5.1 に日本語入りの .ps1 を渡すときは UTF-8 BOM を付ける**。`Chart.Export` のパスは `Join-Path` の結果を変数に入れてから渡す
- **xlsx の図形は openpyxl で保存すると消える**（261013 版で矢印・枠・吹き出しが消えた）。図形のある xlsx は Excel COM で編集する。行の高さを変えるときは図形の Placement を一時的に 2（移動のみ）にする
- LibreOffice は無い。xlsx の再計算・画像化は Excel COM（`CopyPicture`→`ChartObjects().Add`→`Chart.Export`）
- GUI のスクリーンショットは `QT_QPA_PLATFORM` を設定せず `apply_light_theme` ＋ `win.grab()`（offscreen だと日本語が□になる）。言語は MainWindow 作成後に `i18n.set_lang('ja')`
- tools を試すときに結果の出力先（シーケンスの横）が既存データを上書きしうる。担当者のデータには `--out` で別の場所を指定する
- 担当者は「提案・相談」と「作業開始」を分ける。指示前に作らない
