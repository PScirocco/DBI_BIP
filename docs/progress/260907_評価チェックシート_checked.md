# BI-sim 評価チェックシート（実装 vs 仕様）

フェーズA〜E（`bisim/`）の実装が仕様どおりかを担当者が手で評価するためのシート。
バグ出し目的。**判定**欄に `OK` / `NG` / `保留` を記入し、気づきは**メモ**へ。

- 参照: `docs/GUI仕様.md` ／ `docs/progress/260903_review_result_BI-sim.md` ／ `docs/progress/260903_meeting_review.md`
- 対象バージョン: `bisim/__init__.py` の `__version__`（現 `0.1.0-dev`）、commit `db8e724` 時点
- 起動: `python -m bisim`（リポジトリ直下の `.venv`）
- 劣化コアは**暫定モデル**（`source/main.py`）。数値の物理的妥当性は評価対象外（フェーズF）
- スコープ外（評価不要）: 出力マップの画像フォーマット化＋専用ビューア、CPU並列、DBI/BIP補正、実機比較（`GUI仕様.md` 8章）

判定の目安:
- `OK` … 期待動作どおり
- `NG` … 動かない／仕様と違う（メモに現象）
- `保留` … 判断がつかない／仕様側の確認が必要

## 総評

- 仕様と大きくずれている点:
  - SIM Paramの評価チェックNG以外は特に大きくずれているところはありませんでした。
- 使い勝手で気になった点:
  - Resumeのときに日付ファイルが多数作成されるためフォルダ内がごちゃごちゃになることがユーザに分かりにくくさせる。
- 次フェーズ（F：コア統合）前に直したい点:
  - レシピ（ステップ）追加、削除やResumeを何回も実行したり、自由に使っていく中で残存バグがありそうなので、上記の評価メモに記載の不具合を修正後は使いこみたい。直したい点はその後分かると思う。
