##### 劣化シミュレータアプリの画面レイアウト仕様に関するレビュー指摘事項

- 劣化シミュレータアプリのConfigファイル保存
  - 実行シーケンス（ステップ）と各種CSVファイル名の保存
  - シーケンス名（ステップ名）として保存しておくこと
  - アプリメニューに開くがあり、ConfigファイルをLoad／Saveできること
- 命名規則、InputファイルとOutputファイルで仕様を変えること
  - 【Inputファイル】 レシピ名（各ステップ名）_ファイル種別（deg, stat, movie, image, model-param, sim-param, ...）_色（必要なら）.csv とすること
  - 【Outputファイル】 実行シーケンス名（実行ステップ名）_各レシピ名（各ステップ名）_ファイル種別（deg, stat, movie, image, model-param, sim-param, ...）_色（必要なら）.csv とすること
  - InputとOutputで命名規則を変えるのは、レシピ間で共通パラメータを持つこともあるため
  - 実行シーケンス名（実行ステップ名）は劣化シミュレータアプリのConfigファイルとして持つこと
- ログ出力も必要で、簡潔に何をしたのか（入出力ファイル名、動作、パラメータ変更など）を出力するようにすること
- 実行タブに停止ボタンを追加し、押されたらそこまでの結果を保存できるようにすること（保存するか否かをユーザに提示すればよい）、停止段階から後で再開できるようにすること
- 劣化率マップ（_deg_r/g/b.csv）に書かれている数値の意味は、輝度残存率であり、数値が大きいほど劣化してないことを意味していた。よって、アプリ文言の「劣化率」は「劣化率の逆数」(inverse degradation)と表現を変えること
- 劣化率マップや累積ストレスマップはRGB合成画像が必要
- 時系列タブの表示内容については、アルゴリズム担当者間で検討するようになった。だから、今のままで保留とする。UIは白紙のグラフだけ表示しておいて、グラフなどの中身は何も表示しないようにしておけばよい。
- 将来的にスマホ用に大解像度の画像を扱うときの処理高速化について、劣化だけのシミュレーション演算については画素毎に独立しているので、画像分割して並列処理し、最後に合成することで大丈夫である。
- 実行タブの選択ステップ（選択レシピ）のみボタンは、それが押されたらどのステップ（レシピ）を実行するかをそこで選べるようにすること
