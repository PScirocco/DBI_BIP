## B. Aging × 静止画（新規）

同じ絵を **fps=1** で繰り返す（1フレーム＝1秒×ACCEL_RATIO）。
ステップ1＝Aging（`rgbcircle-pattern.png`、初期ストレス なし）、ステップ2＝PQ評価（`rgbcircle-eval_image.png`、初期ストレス 前ステップ継承）の2ステップで確認する。
劣化の数値は⑤「輝度残存率マップ」で円の中にカーソルを置いて読む（R の円なら R、G の円なら G、B の円なら B の値）。

| 項目 | 説明 | 結果 |
|---|---|---|
| B-1 ④の見積り表示 | ステップ1 を ACCEL_RATIO=3600、AGING_TIME=36000（10時間）にして④で選ぶ → 「静止画Aging: 同じ絵を fps=1 で繰り返し（1フレーム = 1秒 × ACCEL_RATIO 3600 = 01h 00m 00s）」「AGING_TIME = 10h 00m 00s → 約10フレーム」と出る | OK |
| B-2 実行と出力 | 全ステップ実行 → ステップ1 は **10フレーム**、Aging 時間 10h 00m 00s で終わる。出力は動画ではなく画像（`…_01_<レシピ名>_image.png`）で、⑤のプレビューに劣化後の絵が出る | OK |
| B-3 劣化の値 | ステップ2 の⑤輝度残存率マップで、R の円 ≈ **0.360**、G の円 ≈ **0.335**、B の円 ≈ **0.124**、背景 = 1.000。評価画像は R の円が水色っぽく、中央（白の部分）が灰色っぽくなる（参考：画素値は R の円＝(160,255,255)、中央＝(160,155,98)） | OK |
| B-4 刻みを細かくした場合 | ステップ1 を ACCEL_RATIO=360、AGING_TIME=36000（同じ10時間）に変えて実行 → **100フレーム**。輝度残存率は R ≈ **0.372**、G ≈ **0.347**、B ≈ **0.162**（画素値 R＝162、G＝157、B＝111）。これは動画で同じ絵を 10時間 Aging した理論テストの値と同じ。B-3 より少しだけ劣化が小さいのは、1フレームの時間（刻み）が細かいほど計算が正確になるため（仕様どおり） |OK|
| B-5 AGING_TIME=0 | ステップ1 を ACCEL_RATIO=3600、AGING_TIME=0 にする → ④は「0（1フレームのみ）→ 約1フレーム」。実行すると 1フレーム（01h 00m 00s）で終わり、R ≈ 0.684、G ≈ 0.722、B ≈ 0.154 |OK|
| B-6 停止・再開 | ステップ1 を ACCEL_RATIO=360、AGING_TIME=3600000（1000時間＝10000フレーム）にして「選択ステップのみ実行」→ 途中で「停止」→ 保存「はい」→ ④の「▶↻ 停止位置から再開」が押せる → 再開すると続きから進み、最後は Aging 時間 41d 16h 00m 00s（＝1000時間）で終わる。完了後、`<出力>/_stops/` の該当フォルダが消える |OK、Stopフォルダを開いたままにすると消えない|
