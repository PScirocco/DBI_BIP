### A-7. AGING_TIME を目標Aging時間として機能させる

既定値は `0`＝無制限（今までと同じ、何もしなくてよい）。以下は**意図的に値を設定して**確認する。

| 判定 | 確認項目 | 期待動作 |
|---|---|---|
|  | 既定0のとき無制限 | 新規レシピの AGING_TIME は `0`。未設定のまま実行すると従来どおり動画を1回再生して終わる（打ち切り・周回なし） |
|  | 単位・精度 | ③の AGING_TIME 欄は秒単位、整数で入力できる（ラベルに「目標Aging時間。0=無制限」の説明がある） |
|  | 打ち切り | 動画Agingレシピで AGING_TIME に小さい値（例: 動画1フレーム分の加速込み時間より少し大きい程度）を設定して実行 → 動画の途中で（最後まで行かずに）打ち切られて正常完了する。**停止扱いにはならない**（④に「停止しました」ではなく「完了」と出る） |
|  | 周回連結 | AGING_TIME に、動画1周分の加速込み時間（≒ 動画の総フレーム数 × (1/fps) × ACCEL_RATIO）より大きい値を設定して実行 → 動画の先頭に戻って繰り返し再生され、目標時間に達するまで続く。出力動画のフレーム数が入力動画の総フレーム数より多くなる |
|  | 停止・再開との併用 | 周回中に「停止」→「▶↻ 停止位置から再開」しても正しく続きから再開でき、最終的に目標時間に到達して完了する |
|  | シーケンス継続 | AGING_TIME で打ち切られたステップの後に続くステップ（PQ評価など）が、打ち切り後の劣化状態を継承してちゃんと実行される |
