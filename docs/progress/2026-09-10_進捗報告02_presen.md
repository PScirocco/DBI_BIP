- **パラメータの CLI 互換**

## 4-2. Config・ファイル命名規則

- **Config 保存**
  - 議事録：実行シーケンスと各種CSVファイル名を保存／シーケンス名として保存／メニューで Load・Save
  - 仕様・実装：`*.seq.json`（シーケンス）＋ `*.recipe.json`（レシピ単体）＋ `bisim_app.json`（アプリ設定）。すべて JSON、日本語もそのまま保存 ✅
- **命名規則を Input と Output で変える**（レシピ間で入力を共有し得るため）
  - 議事録：
    - 入力＝`レシピ名_ファイル種別[_色]`
    - 出力＝`シーケンス名_番号_レシピ名_ファイル種別[_色]`
    - シーケンス名・番号(NN)はアプリ側が持つ
  - 仕様・実装：そのとおり。NN はリスト位置から算出し Config には保存しない ✅
- **ログ出力**
  - 議事録：何をしたかを簡潔に（入出力ファイル名・動作・パラメータ変更）
  - 仕様・実装：画面ログ欄 ＋ `_log_BISim/BISim_YYMMDD.log`（日付ローテーション・容量上限） ✅

## 4-3. 実行ステップ・ステップ設定（②③）

- **②でのファイル指定**
  - 議事録：不可。②はシーケンスの順番を変える等の操作
  - 仕様・実装：②は追加／複製／削除／並べ替えのみ。ファイル指定は③ ✅
- **②→③の順序**
  - 議事録：②で空行を作って③で設定する構成なので、この順序のまま
  - 仕様・実装：この順序で実装 ✅
- **レシピの保存**
  - 議事録：できる
  - 仕様・実装：レシピ単体を `*.recipe.json` で保存／読込。③でモデル表・Sim条件を編集し「適用」で②へ反映 ✅
- **（評価反映）シーケンス名とファイル名**
  - 追加要望：Save 時はファイル名をシーケンス名に一致、Save As 時はファイル名からシーケンス名を取り直す、日本語は非推奨の注意書き
  - 実装：そのとおり。②に「半角英数字推奨」の注意書きを常時表示 ✅

## 4-4. 実行（④）— ステップ選択・中断・停止・再開

- **実行するステップの選択**
  - 議事録：④実行タブで選べるようにする／押したらどのステップを実行するかそこで選ぶ
  - 仕様・実装：④のコンボボックスで単一ステップを選択して実行。「全ステップ実行」も別ボタン ✅
- **中断・再開**
  - 議事録：ファイル出力なし、アプリ側が状態を保持
  - 仕様・実装：メモリ保持のみ、出力なし、計算時間も中断中はフリーズ ✅
- **停止**
  - 議事録：そこまでの結果を保存できるように（保存要否をユーザーに提示）、停止段階から後で再開できる
  - 仕様・実装：停止 → 保存確認 → 出力。「▶↻ 停止位置から再開」で続きのフレームから実行し**連続動画**を出力 ✅
- **（評価反映）停止情報の持ち方** ⚠
  - 追加要望：停止のたびに日時ファイルが増える／再起動後の再開手順が2重
  - 実装変更：停止情報を**シーケンスJSONに内包**（`stops`）。実データは `出力/_stops/<…>/` に**最新1件のみ**。再開は「シーケンスを開く」→ ボタンの1手順

## 4-5. 結果（⑤）

- **劣化率マップのラベル**
  - 議事録：「1/劣化率」に表記変更（明るいところが劣化していない）
  - 仕様・実装：「1/劣化率 / inverse degradation」。累積側も「累積時間 / accumulated time」 ✅
- **RGB合成画像**
  - 議事録：劣化率マップ・累積ストレスマップに RGB合成が必要
  - 仕様・実装：R / G / B / RGB合成 の4表示。カーソル位置の数値も表示 ✅
- **累積時間マップ**
  - 議事録：面内の相対ばらつきを表現
  - 仕様・実装：面内最大で正規化して表示 ✅
- **時系列タブ**
  - 議事録：アルゴリズム担当者間で継続検討、UIは白紙のグラフだけ
  - 仕様・実装：軸のみ・中身なし ✅
- **W の劣化率マップ** ⚠
  - 議事録：ある
  - 仕様・実装：**その後の命名規則確定で W は作らない**（色トークンは r/g/b のみ、RGB合成表示で代替）
