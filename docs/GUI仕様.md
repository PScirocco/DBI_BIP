## 1. 用語

| 用語 | 意味 |
|---|---|
| **レシピ (recipe)** | 1つの処理ステップの定義。入力ファイル参照、モデル/Simパラメータ、初期ストレス設定を持つ。名前を持つ |
| **実行シーケンス (sequence)** | どのレシピをどの順番で実行するかを決めたもの。名前を持つ。＝実行シーケンスConfig |
| **アプリConfig** | アプリ全体の設定（ログ容量など）。実行シーケンスとは別ファイル |
| Aging | 動画入力でパネルを劣化させる処理 |
| PQ評価 | 静止画入力で、蓄積した劣化状態から焼き付き画像を生成する処理 |

---

## 2. 全体構成

- Python / PySide6、5タブ（① フォルダ設定 / ② 実行ステップ / ③ ステップ設定 / ④ 実行 / ⑤ 結果）
- 劣化計算コアは `source/` 側。GUIは**I/F固定で差し替え可能**な形で分離する
- モデル/Simパラメータは**CSV経由で `source/` のCLI版と互換**を保つ（IP設計者がGUIと独立にコアを改良・CLI実行できるように）
- リリースは英語UI。日本語UIは開発者用に残す（`prototype/i18n.py` 相当）
- 明るいグレー基調に固定

## 3. Config（3種・すべて JSON）

### 3.1 アプリConfig

アプリのあるフォルダに配置。

| キー | 内容 |
|---|---|
| `log_max_mb` | `_log_BISim/` の総容量上限 [MB] |
| （将来）既定フォルダ、言語 など | |

### 3.2 実行シーケンスConfig

| キー | 内容 |
|---|---|
| `sequence_name` | 実行シーケンス名。出力ファイル名の先頭に使う |
| `folders` | 入力画像／ヒートマップ／BC設定／モデル／Sim／出力 の各フォルダ |
| `recipes` | レシピの順序付きリスト（各要素は 3.3 の内容、または保存済みレシピへの参照） |

- メニュー「開く」「保存」で Load / Save
- 番号（NN）はリスト内の位置から算出、Config自体には保持しない（アプリ内部で持つ）

### 3.3 レシピ（単体でも保存・再利用可）

| キー | 内容 |
|---|---|
| `recipe_name` | レシピ名。入出力ファイル名に使う |
| `input_image` / `heatmap` | ファイル名（フォルダは 3.2） |
| `model_param` / `sim_param` | インライン値 ＋ 参照CSVファイル名（両方保持） |
| `init_stress` | `none` / `prev`（前レシピのstat継承） / `file`（指定） |
| `init_stress_files` | `file` のときの参照名 |

## 4. ファイル命名規則

`種別` = `deg` / `stat` / `movie` / `image` / `model-param` / `sim-param` …
`色` = `r` / `g` / `b`（**`deg` / `stat` のみ**。`movie` / `image` / `model-param` / `sim-param` は色なし単一ファイル。`w` は作らない）

- `model-param` / `sim-param` は CLI版（`source/` の `degparam_mm.csv` / `simconf.csv`）と同一書式の単一ファイル。`degparam_mm.csv` は「1行 `N,r,g,b`」、`simconf.csv` は「1行 `KEY,値`」。

| 区分 | 規則 | 例 |
|---|---|---|
| **入力** | `レシピ名_種別[_色].拡張子` | `aging01_movie.mp4` / `aging01_model-param.csv` / `pq01_stat_r.csv` |
| **出力（通常完了）** | `シーケンス名_NN_レシピ名_種別[_色].拡張子`（NN＝シーケンス内通し番号 2桁） | `SEQ_A_01_aging01_deg_r.csv` / `SEQ_A_01_aging01_movie.mp4` |
| **出力（停止保存）** | 上記末尾に `_YYMMDD-HHMM` を付加（年月日各2桁＋時分のみ24時間制各2桁） | `SEQ_A_01_aging01_stat_r_260904-1430.csv` |

- Input と Output で規則を変える理由：レシピ間で入力（共通パラメータ等）を共有し得るため、Inputはシーケンス非依存にする
- 前レシピの `stat` を次レシピが継承する場合、参照名は前レシピの**Output名**
- 出力ファイル名トークン `deg` は維持（UIラベルのみ「1/劣化率」に変更）

## 5. タブ別仕様

### ① フォルダ設定
- 6種のフォルダをパス欄＋「参照…」（フォルダダイアログ）で変更。既定値は `source/` の構成
- ③でファイルを選ぶと、その親フォルダがここに反映される

### ② 実行ステップ
- レシピの一覧表示。**追加 / 複製 / 削除 / 並べ替え**
- **ファイル指定は不可**（詳細は③）。ここは順序操作のみ
- ②で空行を追加 → ③で設定、という流れ（②③の順序はこのまま）

### ③ ステップ設定
- 選択中レシピを編集
- プレビュー3面：入力画像 / ヒートマップ / 前回Aging結果（初回・継承なしは非表示）
- 初期ストレス：なし / 前ステップ継承 / ファイル指定
- モデルパラメータ表（直接編集）＋ CSV 読込 / 保存
- Sim条件（ACCEL_RATIO, TMP_L, TMP_H, AGING_TIME）
- BC設定 / 処理パイプライン（BIP・DBI補正・ピーク輝度制御）・A/B比較 … 将来枠・無効表示

### ④ 実行
- ボタン：**全ステップ実行** / **実行するステップを選択**（単一選択） / **中断・再開** / **停止**
  - 中断・再開：メモリ保持、**ファイル出力なし**。同一起動中に再開
  - 停止：**保存要否をユーザーに確認** → 保存する場合はファイル出力（日時付き名）。後で読み込んで継続
- 進捗：全体（step i/N）＋ フレーム（j/M）＋ 処理中フレームのライブ表示
- 時間表示：
  - **計算時間**：実PC計算時間（現状）
  - **Aging時間（加速込み）**：`(処理フレーム数 ÷ fps) × ACCEL_RATIO` をステップ内＋シーケンス累積で。単位は自動（既定：時間）
- ログ：画面表示 ＋ ファイル出力（6章）

### ⑤ 結果
- 表示する idx を選択
- **劣化後プレビュー**：画像／動画（動画はフレームスライダ）
- **1/劣化率マップ**（`_deg_{r,g,b}.csv`）：R / G / B / RGB合成。各チャネル色の輝度表示（**明るい＝劣化していない**）
- **累積時間マップ**（`_stat_{r,g,b}.csv`）：同上。全チャネル最大で正規化
- **時系列**：白紙の軸のみ表示、中身なし（アルゴリズム担当者間で継続検討）
- **A/B比較**：将来対応（補正あり／なし）

## 6. ログ

- 場所：アプリのあるフォルダ直下 `_log_BISim/`（無ければ作成）
- 方式：**日付ローテーション**（1日1ファイル、例 `BISim_260904.log`）
- 総容量が `log_max_mb`（アプリConfig）を超えたら古い日付から削除
- 内容：入出力ファイル名、実行した動作、パラメータ変更 など（簡潔に）

---

## 7. 停止・中断・再開の状態遷移

```
実行中 ──中断──▶ 中断状態（メモリ保持・ファイルなし）──再開──▶ 実行中
実行中 ──停止──▶ 保存する？ ──Yes──▶ ファイル出力（日時付き）──▶ 終了（後で読込→継続可）
                              └─No───▶ 終了（破棄）
```

- DBI / BIP 補正処理の実装
- 実機パネルデータとシミュレータ出力の比較検証、モデル修正
